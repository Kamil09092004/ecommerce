# PHP eCommerce Website with Tracking, Sharing, and Dynamic Pricing

This project is a full-featured **eCommerce web application** developed in **PHP**, with dynamic product tracking, view-based pricing, and social sharing capabilities. It allows users to browse products, track orders, share products, and benefit from dynamic pricing strategies based on popularity.

It uses **MySQL** for the database and additional integrations like **QR code generation**, and **PHPMailer**.

---

## 🔑 Features

- **Product Browsing & Dynamic Listings**: Products are loaded dynamically from the database.
- **Shopping Cart & Order System**: Add, view, and place orders through a responsive interface.
- **Product View Tracking**: Each product view is logged to track popularity.
- **Dynamic Pricing**: Prices adjust based on the number of product views.
- **Most Viewed Products First**: Homepage prioritizes trending items.
- **Product Sharing**: Shareable product pages with QR codes and social features.
- **User Profiles**: Sign-up and login with profile viewing and order history.
- **Notifications**: Send and receive user notifications (includes `send_notification.php`).
- **Order Tracking**: Search and view current order status.
- **Admin Features**: Add products, manage tracking logs, and view analytics.
